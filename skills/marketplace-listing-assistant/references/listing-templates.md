# Marketplace Listing Templates

Category-specific structures optimized for high conversion, minimal back-and-forth, and rapid sales on Facebook Marketplace, Kijiji, and Craigslist.

---

## 1. Electronics (Phones, Tablets, Laptops, Consoles)

```text
[Brand + Model + Storage/Variant] in [Condition Grade]. Fully tested, clean, and ready for a new owner.

Specs:
- Model: [Exact model name & number]
- Storage / Memory: [e.g. 256GB / 16GB RAM]
- Color / Finish: [e.g. Space Gray]
- Battery Health: [e.g. 88% capacity / holds charge great]
- Carrier / Lock Status: [e.g. Factory Unlocked to all networks / iCloud signed out]

Condition:
- Cosmetic: [e.g. Screen is immaculate with glass protector installed; minor scuff on bottom corner as shown in photo #4]
- Functionality: 100% working order. All ports, buttons, speakers, and cameras tested thoroughly.
- Factory reset and wiped, ready for setup.

What's Included:
- [Device]
- [Original charging cable / adapter]
- [Original retail box & inserts]
- [Any bonus cases or screen protectors]

Pickup & Terms:
- Local pickup near [Neighborhood / Public landmark]
- Cash or [Local e-transfer] upon inspection
- You are welcome to power on and inspect everything at meetup
- Priced to sell quickly — firm price.
- If the ad is visible, it is available!
```

## 2. Computer Parts & Peripherals (GPUs, Monitors, Keyboards)

```text
[Brand + Model] in excellent working condition. Pulled from a clean, well-ventilated personal setup.

Key Specs:
- [Clock speed / VRAM / Switch type / Resolution / Refresh rate]
- [Ports: DisplayPort, HDMI, USB-C]
- [Power requirement / Dimensions if GPU]

Condition & History:
- Never mined on, never overclocked, used only for light gaming/work.
- Clean and dust-free.
- Thermals and benchmark performance run as expected.

What's Included:
- [Item name]
- [Anti-static bag / original packaging / mounting screws / cables]

Pickup & Terms:
- Pickup in [Area]
- Cash or e-transfer preferred
- Firm price. Lowballs ignored.
```

## 3. Furniture & Home Goods

```text
[Brand / Style] [Item Name] in [Color / Material]. Sturdy, well-maintained, and stylish piece.

Dimensions:
- Width: [X inches / cm]
- Depth: [X inches / cm]
- Height: [X inches / cm]

Condition:
- Very clean and structurally solid.
- [Honest notes on surface wear, scratches, or fabric condition].
- Kept in a smoke-free and pet-free home.

Logistics & Transport:
- Ground floor pickup / elevator building / needs two people to carry.
- [Can / cannot be disassembled].
- Please bring moving blankets/straps if needed.
- Cash or e-transfer on pickup.
```
